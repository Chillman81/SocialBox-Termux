01 / The project

From terminal utility
to learning resource.

SocialBox Termux is a historical shell-based project designed for Android’s Termux environment. Its original scripts target social platforms and include credential-guessing workflows.

This website does not run those scripts, collect credentials, or provide an attack interface. Instead, it gives learners a safe overview and points to defensive practice.

02 / Safety first

Authorization is
not optional.

!

Use responsibly

Attempting to access an account without the owner’s explicit, informed permission is illegal and harmful. Do not test real accounts or services. Use a local lab, intentionally vulnerable application, or a written engagement scope.
